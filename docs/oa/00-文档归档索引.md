# 中小企业 OA 文档归档索引

## 文档定位

本目录依据对话《设计中小企业OA系统》整理，作为 OA 项目的需求分析与研发文档入口。

当前结论：项目已进入增量开发阶段，基础平台、核心审批业务、人事档案、考勤和劳动合同模块已有可运行实现；本目录持续作为 PRD、API、数据库、权限、生产门禁和验收基线，新增模块先归档规格再开发。
