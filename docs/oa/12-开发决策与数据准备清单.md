# 开发决策与数据准备清单

## 1. 已确认决策

| 项目 | 决策 |
|---|---|
| 首发终端 | Web；响应式适配手机浏览器，不开发原生 App 或企业 IM 集成 |
| 演示租户 | xxx公司 |
| 前端 | Vue（建议 TypeScript + Vue 3 + Vite + Element Plus） |
| 主后端 | C# + ASP.NET Core（建议采用当前 LTS .NET 版本） |
| 初始数据 | 使用模拟数据，后续保留导入能力 |
| 数据可见范围 | 上级可查看下级范围数据；财务可查看全公司报销数据 |
| 年假 | 按中国法定最低标准与累计工作时间计算；使用中国工作日历 |
| 病假材料 | 支持附件上传，由审核人判断材料是否合格 |
| 请假审批 | 3 天及以内由部门领导审批；超过 3 天增加总经理审批 |
| 数据库 | PostgreSQL |
| 运维 | 必须具备日志、监控、告警、备份、恢复和可追溯审计能力 |

年假法定最低标准：连续工作满 12 个月后，累计工作满 1 年不足 10 年为 5 天，满 10 年不足 20 年为 10 天，满 20 年为 15 天；法定节假日和休息日不计入年休假。累计工作时间可包含不同用人单位的全日制工作期间及法定视同工作期间。详见[国务院《职工带薪年休假条例》](https://xzfg.moj.gov.cn/front/law/detail?LawID=208&Query=%E4%BC%91%E5%81%87)及[人社部《企业职工带薪年休假实施办法》](https://www.mohrss.gov.cn/xxgk2020/gzk/gz/202112/P020211229590352867273.pdf)。

## 2. 首发默认费控与付款策略

- 费用类别：交通、住宿、餐饮招待、办公、通讯、培训、其他；都需关联发票或其他合规凭证。
- 审批路径：部门负责人 → 财务专员；金额超过 1,000 元增加财务经理，超过 5,000 元再增加总经理。
- 预算：首发默认关闭，但保留预算开关与超预算标记；开启后默认允许提交并增加财务经理复核，可配置为禁止提交。
- 付款：财务专员在审批完成后录入线下付款日期、方式、流水号、金额和凭证；只允许全额一次付款。

这是适合中小企业首发的通用控制方案；流程和阈值通过配置维护。电子票据报销与归档可以纳入流程化管理，相关实践见[国家档案局电子发票电子化报销、入账、归档案例](https://www.saac.gov.cn/daj/qydagz/202103/4b1266cca17144dab5b99902e5ec6639/files/dc6a17aef4d64459a3a4e8dbbfbb86ce.pdf)。

## 3. 技术栈基线

推荐采用前后端分离：

| 层级 | 推荐 | 原因 |
|---|---|---|
| 前端 | TypeScript + Vue 3 + Vite + Element Plus | 已确认 Vue 偏好；适合后台表单、表格、权限与响应式页面 |
| 后端 | **C# + ASP.NET Core** | 已确认；适合事务、权限、审计、异步任务和跨平台部署 |
| ORM/数据访问 | EF Core + Dapper | EF Core 管理事务和实体关系；Dapper 承担复杂列表与报表 SQL |
| 流程 | 自研轻量工作流模块 | 以标准节点、条件路由和审批任务落地，保持业务模型可控 |
| 数据库 | PostgreSQL | 已确认；适合事务、JSON 扩展、全文检索和索引 |
| 缓存/任务 | Redis | 会话、限流、短期缓存、异步任务协调 |
| 文件 | MinIO（开发/私有部署）或兼容 S3 的对象存储 | 附件隔离、版本和扩展性 |
| 部署 | Docker Compose 起步，Nginx 反向代理 | 可重复部署，便于后续演进 |
| 运维 | OpenTelemetry + Prometheus + Grafana + Loki | 指标、日志、链路与告警可观测 |

后端按 .NET LTS 生命周期选定稳定版本；具体依赖版本在项目初始化时锁定。后续 OCR、AI、文档解析等能力可按需增加独立 Python 服务，不影响主业务后端。

## 4. 模拟数据基线

首个演示租户建议预置：总经理、财务部、行政人事部、研发部、销售部；每部门 3–6 名员工；至少 1 名部门负责人、1 名财务专员、1 名财务经理。预置年假累计工龄 0.5、3、12、22 年四类员工，覆盖无年假、5、10、15 天规则和阈值审批测试。
