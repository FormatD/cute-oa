# 企业知识库与制度文档 PRD

## 1. 产品目标

企业知识库与制度文档中心用于集中管理和沉淀企业内部的规章制度、标准作业指引、办事流程指南、合同/公文/表格范本及各部门知识资料。
通过目录分类体系、文档版本化管理与修订历史记录，确保员工及时获取最新、最准确的企业规范；通过“必读制度签收”机制，实现重要合规制度（如员工手册、保密协议、安全规范）在全员或指定部门范围内的下发、阅读确认与统计追溯，满足企业用工合规与内部治理审计要求。

V1.0 面向中小企业通用知识管理与制度分发，覆盖 Web 响应式界面。支持富文本/Markdown 说明、附件上传与安全下载、版本历史迭代、全员或部门可见性控制、必读签收确认看板。暂不实现企业级复杂全文分词搜索引擎、AI 智能问答与外部知识库同步，后续通过独立 AI 助手模块扩展。

## 2. 角色与权限

| 角色 | 能力 |
|---|---|
| 普通员工 | 浏览和检索可见范围内的已发布制度/文档；阅读正文与下载附件；对被标记为“必读”的制度进行阅读并在线签署确认；查看本人已确认记录 |
| 部门负责人 | 浏览本部门及全员文档；查看团队成员在必读制度上的确认签署进度 |
| 知识管理员（HR/行政/体系专员） | 维护目录分类体系（增删改排序）；创建、编辑、发布、修订新版本、归档制度与文档；上传和管理制度附件；配置必读要求；查看全员制度签收看板并进行催办提醒 |
| 系统管理员 | 拥有最高知识管理权限，可跨所有分类维护文档，配置角色与操作审计 |

新增权限点：
- `DOCUMENT_VIEW`：浏览与检索可见目录中已发布文档、下载附件、签署确认（所有在职员工默认具备）；
- `DOCUMENT_MANAGE`：维护目录分类、编写草稿、发布文档、修订升级版本、归档文档、查看全员签收统计看板。

生产环境安全策略：
- `DOCUMENT_MANAGE` 涉及全员正式规章制度发布与合规凭据，纳入生产多因素认证（MFA）强制保护清单。

## 3. 页面范围与交互规范

### 3.1 知识库主页 `/documents`
- **必读制度待签收告警栏**：若当前员工存在尚未签收确认的必读制度，在顶部以高亮横幅提示，列出待办条数并提供快速直达通道。
- **分类导航树**：
  - 支持左侧分类层级树（支持全公司公开分类与部门专有分类）。
  - 内置快捷筛选标签：“全部”、“最新发布”、“必读制度”、“表格范本”、“我已签收”。
- **文档列表区**：
  - 检索栏：支持按关键字（标题、文号、摘要、标签、正文）即时过滤。
  - 文档展示卡片/列表：显示文档编号、标题、分类、最新版本号（如 v1.0、v2.0）、更新时间、阅读量/下载量、标签以及“必读待签收”或“已签收”状态徽标。
  - 操作：管理员支持“＋ 新增制度/文档”与“目录分类管理”。

### 3.2 文档详情页 `/documents/:id`
- **基本信息与正文**：
  - 标题、文档编号（如 `DOC-202609-0001`）、所属分类、生效日期、失效日期、发布人、发布时间、版本号。
  - 正文区域支持 Markdown 格式解析渲染（段落、表格、有序/无序列表、引用提示框）。
- **附件列表与下载**：
  - 展示关联的原文件（PDF、Word、Excel 等），显示文件名与大小。
  - 点击下载受权限控制，系统校验调用者可见性，并记录附件下载审计流水。
- **版本历史与修订记录**：
  - 展示该文档的历史版本列表（版本号、发布时间、发布人、修订变更说明）。
  - 支持切换查看历史版本的正文与对应附件。
- **必读制度在线签收面板**（仅对标记为必读且当前适用的文档）：
  - **员工视角**：如未签收，展示《合规阅读与承诺确认书》条款及“我已认真阅读并承诺严格遵守”按钮；点击后记录员工 ID、姓名、确认时间、IP 地址和签署版本；已签署后显示绿色“✓ 已于 2026-09-04 10:00 完成签收”凭据。
  - **管理员视角（签收统计看板）**：
    - 统计卡片：应签人数、已签人数、签收率百分比。
    - 人员名单折叠面板：可切换“已签署（附签署时间）”与“待签署（附所属部门、上级）”名单。
- **管理操作**（具备 `DOCUMENT_MANAGE` 权限可用）：
  - “修订发布新版本”：版本号自动递增（如 v1.0 -> v1.1 或 v2.0），录入修订说明，可更新正文和附件。
  - “归档文档”：将文档转为归档状态，归档后普通员工不可在主列表检索，仅管理员可见。

### 3.3 新建/编辑文档弹窗
- 标题（必填，1–100 字符）；
- 分类（必填，从现有有效分类中下拉选择）；
- 适用范围（全公司公开 / 指定特定部门）；
- 生效日期（必填，默认当日）；
- 失效日期（可选，为空表示长期有效）；
- 标签（可选，多个标签以逗号分隔，便于多维检索）；
- 是否必须签署（布尔开关：开启后触发必读签收逻辑与工作台待办提醒）；
- 摘要（必填，1–300 字符）；
- 正文（必填，Markdown 格式，1–20000 字符）；
- 附件（可选，通过系统安全上传组件上传，支持 0–10 个附件）。

## 4. 业务规则与状态机

### 4.1 文档状态机
- `Draft`（草稿）：编制中，仅创建人和具备管理权限者可见；
- `Published`（已发布）：对适用范围内的员工全员生效可见；若为必读制度，向适用员工派发通知；
- `Archived`（已归档）：制度废止或失效，从公共列表下线，保留历史追溯。

### 4.2 必读签收规则
1. 文档发布为必读时，系统锁定该版本快照；
2. 目标员工（全员或所属部门员工）只要处于在职状态（`ACTIVE`），均纳入应签收名单；
3. 员工每次签收对应特定的版本号（如员工签收了 v1.0）；当管理员发布重大修订（如升级为 v2.0 且勾选重新要求签收），系统重置待签署状态，保障员工始终认可最新版本；
4. 签收记录不可物理删除，作为劳动用工与合规审计证据永久归档。

### 4.3 分类可见性与层级
- 分类编码唯一性约束；
- 分类指定部门时，仅该部门及下级部门员工可浏览该分类下的文档；未指定部门的分类对全公司可见。

## 5. 异常错误码规范

| 错误码 | 说明 |
|---|---|
| `DOC_001` | 参数校验不合法（标题、正文、分类等超出长度或为空） |
| `DOC_002` | 目录分类不存在或试图删除包含有效文档的分类 |
| `DOC_003` | 文档不存在或超出当前用户可见范围 |
| `DOC_004` | 非法状态流转（例如对未发布文档执行签收、重复签收同一版本） |
| `DOC_005` | 必读签收失败或签收人非有效在职员工 |
| `AUTH_002` | 无权执行管理操作（缺少 `DOCUMENT_MANAGE`） |
| `FILE_005` | 包含无效或越权附件 |
