# 人力资源模块生产就绪清单

## 1. 当前结论

人事档案、员工生命周期、考勤基础和劳动合同台账已经达到“单公司、单节点生产候选”状态：业务数据持久化、服务端权限、敏感合同独立范围、乐观锁、附件关联、审计、合同预警幂等派发、存活/就绪检查和 PostgreSQL 回归用例已具备。

这不等于可以无条件直接上线。正式承载真实员工和签署合同前，必须完成本清单 P0 项；未完成的项目不能通过上线审批。

## 2. 已完成能力

| 能力 | 当前实现 |
| --- | --- |
| 人事主数据 | 花名册、详情、入转调离状态、岗位/部门/上级联动、只追加事件 |
| 考勤 | 默认班次、工作日历、导入/人工录入、异常计算、本人申诉、HR 审核、月报、月度封账/解封与审计 |
| 劳动合同 | 三类合同、草稿/激活/续签/终止、签署附件、试用期校验、重叠保护、版本链 |
| 敏感权限 | `Contract` 独立数据范围；上级不会因管理链自动查看下属合同 |
| 预警 | 90/60/30/7 天分档、确认记录、后台周期派发、数据库唯一去重 |
| 安全基础 | PBKDF2 密码、失败锁定、短期 JWT、HttpOnly 刷新 Cookie、会话撤销 |
| 运维基础 | EF Core 增量迁移、`/health`、`/health/ready`、开发/生产模拟功能隔离 |
| 验证 | 后端零警告构建、前端生产构建、领域测试和隔离 PostgreSQL 集成测试 |

## 3. 上线前 P0 门禁

- [ ] 通过环境变量注入至少 32 字节且与开发环境不同的 `Authentication__SigningKey`；生产密钥进入密钥管理系统，不写入镜像或仓库。
- [ ] 设置 `ConnectionStrings__OaDatabase`，使用独立生产账号、最小权限、TLS 连接和连接池限制。
- [ ] 设置 `Cors__AllowedOrigins__0` 等明确的 HTTPS 前端来源，禁止通配来源配合凭据 Cookie。
- [ ] 为 `Storage__Root` 挂载持久化加密卷，并验证应用用户只有所需目录权限；附件目录必须纳入备份。
- [ ] 保持 `DemoFeatures__AllowDataGeneration=false`，确认生产页面调用模拟数据接口时被服务端拒绝。
- [ ] 在预发布环境执行两次数据库备份与一次恢复演练，记录恢复点目标、恢复时间目标和责任人。
- [ ] 部署平台接入 `/health` 与 `/health/ready`，就绪失败停止流量；接入 5xx、登录失败、后台预警失败和磁盘容量告警。
- [ ] 使用真实组织副本完成 HR、员工、部门负责人、系统管理员四角色验收，并由人事/法务确认合同规则与提示文案。
- [ ] 完成附件恶意文件扫描或在入口网关阻断；未完成前只允许受控 HR 网络上传合同文件。
- [ ] 配置 HTTPS、反向代理可信地址和安全响应头；验证刷新 Cookie 在生产请求中带 `Secure`。

## 4. 已知边界

- 当前租户仍固定为 `demo`，适合单公司独立部署，不适合多个公司共享同一实例。多租户上线前必须改造租户上下文和全链路隔离测试。
- 附件使用本地文件系统，没有对象存储、病毒扫描、在线预览、文件版本和自动生命周期；单节点挂载持久卷可用，但横向扩容前必须抽象共享存储。
- 考勤尚无员工排班、外部打卡设备接入、月报签字快照和薪资结算接口；月度封账与受审计解封已具备。
- 合同模块提供规则提示，不自动作劳动法结论；电子签名、印章、工资和身份证等高敏字段不在当前范围。
- 系统尚无 MFA、IP/账号组合限流、字段级脱敏和 SIEM 对接；真实公网暴露前应补齐。
- 后台预警当前发送站内通知，不含短信、邮件或企业微信渠道。

## 5. 推荐发布流程

1. 在预发布库运行全部迁移与 `bash scripts/verify.sh`、`bash scripts/verify-postgres.sh`。
2. 导入脱敏组织与少量合同，验证权限矩阵、附件下载、续签链和预警去重。
3. 备份生产库，维护窗口内运行增量迁移；不执行任何重置脚本。
4. 启动单实例，等待 `/health/ready` 成功后再切流；观察日志和资源 30 分钟。
5. 由 HR 完成关键用例签字，保留回滚版本和数据库备份；迁移含不可逆数据变更时禁止仅靠应用回滚。
